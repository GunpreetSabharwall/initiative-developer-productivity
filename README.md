# Developer Productivity (demo initiative)

**Lakeshore Components is a fictional company.** This repository is one of five demo initiatives that
[Program Hub AI](https://github.com/GunpreetSabharwall/Program-Hub-AI) and
[Agentic Earned Value](https://github.com/GunpreetSabharwall/agentic-earned-value) read for talks and demos by Gunpreet Sabharwall.

**Story:** CI and developer tooling, mostly human, two blockers: late but efficient, a schedule problem not a cost problem.

Plan: 2026-09-21 for 12 weeks, two teams: **CI** (`pod-ci`) and **DevEx** (`pod-devex`).

## This is a plain source repository

Nothing from Program Hub or AEV is installed here; both read it from outside. Budget, rates, human hours and
agent costs are kept by the PMO in Program-Hub-AI (`initiatives/developer-productivity/`), and AEV's results are written there too.

How it is kept (the requirements):

- Every piece of work is an issue with a size label `aev-points:N` and a team label.
- Every pull request names its issue: `Fixes #N` when it finishes it, `Part of #N` for partial work.
- Agent-written pull requests carry the `aev-agent` label; their commits are authored by `coding-agent`.
- Blocked work carries the `blocked` label. Mistakes are undone with GitHub's **Revert** button.

Full requirements: [Program Hub](https://github.com/GunpreetSabharwall/Program-Hub-AI/blob/main/docs/REPO-REQUIREMENTS.md) ·
[AEV](https://github.com/GunpreetSabharwall/agentic-earned-value/blob/main/docs/REPO-REQUIREMENTS.md).

## Demo stage slots

Three agent pull requests are held back so the live “revert” moment can be shown three times:

| Slot | Held PR | Issue |
|---|---|---|
| 1 | #37 | #10 |
| 2 | #34 | #11 |
| 3 | #38 | #12 |

Before a demo: **Actions → Prepare stage → Run workflow** (uses the next free slot), then run **Program Dashboard**
in Program-Hub-AI. On stage: open the slot's PR, click **Revert**, merge the revert PR, and run Program Dashboard again.

## Setting it up

1. Settings → Actions → General → Workflow permissions → tick **Allow GitHub Actions to create and approve pull requests**.
2. **Actions → Seed demo → Run workflow** (about 10 minutes; it resumes if stopped). The repository must be empty of issues and PRs first.

History generated by `examples/portfolio/build_portfolio.py` in agentic-earned-value.
